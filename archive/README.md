# Historical material

`generated_package/` contains the original study reports, analyses, workbook and
experiment settings. Its CSVs now live in `data/generated/` at the project root.
`reports/` retains historical completion evidence and research material.

Dataset-building and packaging executables have been removed. Commands and paths
inside historical reports are obsolete; follow the root README for current usage.
Historical output under `results/` is not an application input.
